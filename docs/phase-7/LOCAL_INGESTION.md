# Phase 7 — Mac-Native Media Ingestion

## Purpose

Turn one **authorized local media file** into one **Clipper project** and one
**verified, FFmpeg-backed processed artifact**, then emit a small, versioned
contract that Stadium Signal Lite can consume.

This is the first honest end-to-end loop between the two repositories:

```text
local authorized video
  -> register as a project (managed pilot job + rights gate)
  -> deterministic EDL (one straight-cut segment)
  -> genuine FFmpeg reference render
  -> verify artifact (exists, readable duration, provenance to source)
  -> versioned integration contract for Stadium Signal Lite
```

## Scope And Guardrails

- **Additive.** Nothing in the World Cup reference deployment is changed. The
  module only calls existing services (`pipeline.pilot`, `pipeline.edl`,
  `pipeline.rendering`). `validate_data.py` and `pytest` keep passing.
- **Separate repositories.** The Clipper lives in `worldcup-clipping-pipeline`;
  Stadium Signal Lite lives in `stadium-signal-lite`. This contract is the only
  coupling.
- **Non-production test project.** The built-in project is the registered,
  `production_capable=false` `basketball_sandbox` profile. The `football`
  (World Cup) profile is never selected by this workflow.
- **Local-first.** By default no worker process is exposed, no OORT is required,
  and no network requests are made. The only subprocesses are `ffprobe`
  (read-only metadata) and `ffmpeg` (the render), both invoked with structured
  arguments, never a shell. Phase 7.1 adds an **opt-in** OORT Storage upload
  (see [`STORAGE_INTEGRATION.md`](STORAGE_INTEGRATION.md)); it is off unless
  explicitly requested and the run continues locally when OORT is unavailable.
- **Runtime is isolated.** Job records, EDLs, and renders are written under an
  explicit job root (`data/pilot/`, gitignored, or a caller-provided `tmp`
  directory). Media files are never copied, moved, renamed, or re-hosted.

## Module And CLI

- `pipeline/local_ingest.py` — the orchestration module.
- `scripts/local_ingest.py` — the operator CLI.

### Full run

```bash
python3 scripts/local_ingest.py run \
    --source ~/FootballArchive/TESTS/capture_test.mp4 \
    --pilot-id ss_lite_local_001 \
    --jobs-dir data/pilot/jobs \
    --intake data/pilot/intakes/ss_lite_local_001.json \
    --out data/pilot/contracts/ss_lite_local_001.contract.json
```

The command exits `0` only when the artifact verifies (exists, readable
duration, provenance linked). It refuses to proceed unless the intake is
execution-ready: structurally valid, configuration references resolve, the
source passes read-only validation, and the rights gate is cleared.

### Register only

```bash
python3 scripts/local_ingest.py register --intake path/to/intake.json
```

### Re-verify a previously emitted contract

```bash
python3 scripts/local_ingest.py verify --contract path/to/contract.json
```

## Processing Stages: Real, Mocked, Unavailable

Every contract records a machine-readable `stages[]` block. The current state:

| Stage | Status | Detail |
| --- | --- | --- |
| `source_registration` | **real** | `pilot.validate_intake` + `create_job` (structural, config, source, rights) |
| `source_probe` | **real** | `ffprobe -show_format -show_streams` (read-only) |
| `rights_gate` | **real** | `pilot` CONFIRMED + unexpired rights gate |
| `edl_build` | **real** | `edl.write_edl` (single straight-cut segment) |
| `ffmpeg_reference_render` | **real** | `rendering.render_edl`, `mode=REFERENCE` (real FFmpeg) |
| `artifact_provenance` | **real** | SHA-256 of source + artifact, duration re-probe |
| `transcription` | **unavailable** | requires a faster-whisper model; not run for ingestion |
| `moment_detection` | **unavailable** | requires an LLM/Ollama detection provider; not run for ingestion |
| `editorial_render` | **unavailable** | `mode=EDITORIAL` not selected; only the reference render is exercised |
| `delivery` | **mocked** | delivery metadata recorded only; no publish to a downstream channel |
| `network_worker_oort` | **unavailable** | no separate worker process; OORT upload is adapter-direct when enabled |
| `oort_storage_upload` | **real / unavailable** | **real** only when an opt-in upload + verification succeeds; otherwise `unavailable` |

In short: **registration, probing, the rights gate, EDL construction, the
FFmpeg render, and provenance verification are genuinely real.** Transcription
and moment detection are deliberately out of scope for ingestion and are
reported `unavailable`, not faked. The editorial renderer exists but is not
exercised here. Delivery is recorded as metadata only. The optional OORT upload
stage is `real` only when an upload actually happened and verified; it is
`unavailable` when no upload was requested or OORT is not configured.

## Integration Contract

- Human description: this document.
- JSON Schema: [`docs/contracts/local_ingest_result.v1.json`](../contracts/local_ingest_result.v1.json).
- Schema id: `stadium_signal.local_ingest/v1`, version `1`.

The contract references, without embedding, the project (`job_id`,
`project_id`, `reference_deployment`), the source (path + SHA-256 + media
facts), the processing operation (EDL + render mode + the exact `ffmpeg_argv`),
the artifact (path + SHA-256 + duration), and a `provenance` block that ties the
artifact back to the source. Stadium Signal Lite consumes this file locally; it
does not need the worker.

`pipeline.local_ingest.validate_integration_contract` enforces the envelope
before it is written, and the CLI `verify` subcommand re-checks a stored
contract against the on-disk artifact and source.

The contract also carries an additive, optional `storage` block (Phase 7.1) that
records an OORT Storage upload when one was requested: a private `s3://` object
reference, the artifact checksum, the ETag, the verified flags, and any error.
It is `status: "skipped"` for the ordinary local-only run, so existing consumers
are unaffected.

## Optional OORT Storage (Phase 7.1)

Uploading the verified artifact to OORT Storage is opt-in and off by default.
See [`STORAGE_INTEGRATION.md`](STORAGE_INTEGRATION.md) for the full guide,
provider findings, and health check.

```bash
# verify connectivity/credentials only (no upload)
python3 scripts/local_ingest.py storage-health

# opt-in upload + verification of the artifact
python3 scripts/local_ingest.py run \
    --source ~/FootballArchive/TESTS/capture_test.mp4 \
    --pilot-id ss_lite_local_001 --upload \
    --out data/pilot/contracts/ss_lite_local_001.contract.json
```

Local artifacts are always preserved, even when a required upload fails.

## Tests

```bash
.venv/bin/python -m pytest tests/test_local_ingest.py -q
```

The suite generates a synthetic video with FFmpeg and asserts the full loop:
registration creates a `READY` project, the reference render completes, the
artifact duration is readable and matches the EDL timeline, provenance links to
the source, tampering with the source breaks the provenance link, the contract
self-validates, and the default World Cup job root is never touched. Tests skip
cleanly when FFmpeg/ffprobe are absent.
