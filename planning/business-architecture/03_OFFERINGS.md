# Offerings

## Purpose

Customers buy outcomes before they buy software. This document defines offers that can be sold and operated manually first. Repeated delivery patterns can later become software-supported workflows.

## Managed Content Production

Description:

- Convert long-form or live media into reusable content outputs through a managed workflow and human review.

Inputs:

- Source video files or recordings.
- Brand guidelines.
- Clip goals.

Outputs:

- Platform-ready content outputs.
- Captions or post copy.
- Delivery folder.

Best for:

- Sports teams, leagues, podcasts, conferences, creators.

Current repo support:

- Partially supported through transcription, content analysis, manifests, exports, and static review.

## Game Highlight Production

Description:

- Produce highlight packages from games or matches.

Inputs:

- Full game files.
- Team/player metadata.
- Event context.

Outputs:

- Vertical social clips.
- Optional story packages.
- Clip manifest.

Best for:

- Sports leagues, teams, tournaments, esports.

Current repo support:

- Strong for soccer-style workflows, partial for other sports.

## Social Content Operations

Description:

- Recurring content production for organizations with weekly or daily source media.

Inputs:

- Ongoing content sources.
- Posting calendar.
- Brand rules.

Outputs:

- Repeated clip batches.
- Production status reports.

Best for:

- Teams, leagues, creators, podcasts.

Current repo support:

- Manual only beyond the core media processing scripts.

## Podcast Production Workflow

Description:

- Convert podcast or interview episodes into quote clips and social assets.

Inputs:

- Episode video/audio.
- Guest names.
- Topic priorities.

Outputs:

- Quote clips.
- Caption files.
- Social copy.

Best for:

- Podcasts, interview shows, business media.

Current repo support:

- Transcription and export are reusable; detection templates are missing.

## Creator Automation

Description:

- Process creator streams or VODs into recurring clip batches.

Inputs:

- Stream recordings.
- Creator tone.
- Moment preferences.

Outputs:

- Funny/reaction/win/loss clips.

Best for:

- Streamers and creators with consistent content volume.

Current repo support:

- Weak until stream and chat adapters exist.

## Conference Media Processing

Description:

- Turn conference session recordings into speaker highlights and LinkedIn-ready clips.

Inputs:

- Session recordings.
- Agenda.
- Speaker names.
- Brand rules.

Outputs:

- Speaker clips.
- Quote clips.
- Session summaries.

Best for:

- Conferences, business events, education events.

Current repo support:

- Medium for file processing, weak for speaker-aware metadata.

## Media Archive Processing

Description:

- Process historical media libraries into organized clips and metadata.

Inputs:

- Archive files.
- Rights metadata.
- Search priorities.

Outputs:

- Clip candidates.
- Metadata catalog.
- Exported asset library.

Best for:

- Sports archives, media companies, event organizers.

Current repo support:

- Partial through CSV-first archive conventions.

## Custom Workflow Development

Description:

- Build custom source adapters, templates, or production flows for a client.

Inputs:

- Workflow requirements.
- Access credentials.
- Success criteria.

Outputs:

- Client-specific operating workflow.
- Documentation.

Best for:

- Higher-value clients with repeated needs.

Current repo support:

- Possible, but should be scoped carefully to avoid forks.

## Workflow Consulting

Description:

- Help clients design content operations even before automation.

Inputs:

- Current production process.
- Goals and constraints.

Outputs:

- Workflow map.
- Automation recommendations.
- Pilot plan.

Best for:

- Clients unsure where to start.

Current repo support:

- Supported by audit and blueprint documentation, not by code.
