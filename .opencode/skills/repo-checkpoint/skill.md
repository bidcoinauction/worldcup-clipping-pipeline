## What I do

I help create clean commits.

## Rules

Before committing:

1. Run tests.
2. Run `git status`.
3. Identify unrelated modified, deleted, or untracked files.
4. Do not stage unrelated files.
5. Restore accidental deletions before commit.
6. Use a clear commit message.
7. Show final status after commit.

## Commit style

Prefer small commits:

- One behavior change per commit.
- One refactor per commit.
- One cleanup per commit.
- Do not mix docs cleanup with code behavior.

## When to use me

Use this skill before staging, committing, restoring files, or cleaning git status.
